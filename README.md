# live-sports-service

This project is meant to be a TUI that you can use to look at live sports scores and statistics. This is a Rust-based tool that I am building as a little personal project to help myself learn Rust. Depending on how it goes will directly affect how much polish I decide to apply to the project.

For the MVP, I will be focusing on baseball scores (MLB + WBC). However, if everything goes as I envision it, it should be relatively easy to extend this to other major sports like CBB, NBA, etc.

## Planned Features for MVP
- View MLB + WBC live scores/results
- View details about individual MLB + WBC matchups
